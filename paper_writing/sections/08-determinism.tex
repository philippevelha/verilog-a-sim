\section{Bit-Identical Results Across Platforms and Thread Counts}
\label{sec:determinism}

A simulator's output usually differs in its last digits between machines: a parallel reduction
sums in a different order, a vendor math library rounds \texttt{exp} differently, a BLAS kernel
fuses a multiply-add on one CPU and not another. \vas{} removes each source.

\todo{The rules, each with the version that introduced it and the difference it removed:
(1) the linear algebra library is pinned to sequential execution, because its default
parallelism made answers depend on the core count (found 2026-09-25);
(2) every transcendental function comes from \texttt{libm}, a pure-Rust port of musl's, rather

(3) device evaluation runs in parallel but its stamps are recorded and replayed in a fixed order;
(4) a scalar dense LU (1.31.0) instead of a SIMD kernel, which removed the last macOS difference;
(5) Rust neither fuses $a - f b$ into an FMA nor reorders a floating-point reduction unless asked.}
