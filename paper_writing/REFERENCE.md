# Reference runs — mrm_tcmt in ngspice (OSDI) and verilog-a-sim

Generated by `make_reference.py` on 2026-10-23, 2-vCPU x86-64 cloud VM.
Re-run and compare:

```
python3 make_reference.py --out rerun            # full set, ~90 s here (tight va-sim run ~46 s)
python3 make_reference.py --out rerun --skip-tight --repeats 2   # quick, ~15 s
python3 check_rerun.py outputs rerun
```

`check_rerun.py` passes a case only if the point count, x-range and dt min/median/max are
identical (the step sequence is deterministic) and the waveform matches to print precision.
Times and memory are reported as ratios, for information only.

Tools: ngspice-47 (master a80f6e3, built with `--enable-osdi`), OpenVAF-reloaded 5063fda
(LLVM 18), verilog-a-sim 2.42.0 (7321404, built with rustc 1.97 — the pinned 1.92 could not
be downloaded here). Paths can be overridden with `NGSPICE`, `VACLI`, `OPENVAF`.

## verilog-a-sim switches tested (va_tran case, model v2)

| Variant | Points | Wall (s) | RSS (MB) | Output |
|---|---|---|---|---|
| default | 24 650 | 1.80 | 7.8 | — |

| `--bypass` | 24 650 | 1.76 | 7.9 | round-off level |
| `VA_JIT=on --bypass` | 24 650 | 1.73 | 15.8 | round-off level |
| `VA_COLLAPSE=on` | 24 650 | 1.94 | 7.8 | identical |
| `--solver sparse` | 24 650 | 1.88 | 7.9 | round-off level |
| `VA_SCHED=off` (tree-walk evaluation) | 24 650 | 3.40 | 7.6 | identical |
| `--integration gear` | 24 459 | 1.82 | 7.8 | RMS ΔP/P̄ 1.2e-4 |
| `--integration be` | 61 657 | 5.56 | 10.3 | RMS ΔP/P̄ 9.9e-4 |

`mrm_tcmt.va` v1 (analog function `qdep()`, `ddt()` inside sums) fell back to the tree walk
(`xtask sched-check`: "a non-maths call reads a variable"; driver: "ddt inside an expression"),
so `VA_JIT` had no effect and the run took 3.1 s. v2 inlines `qdep`, gives each `ddt()` its own
contribution and writes the `$limit` arguments from parameters only; both models are then on
the static path, the outputs are unchanged (max diff 1e-15 va-sim, 6e-13 ngspice, same step
sequences), and the run takes 1.8 s (1.63 s with the JIT).

Profile of the remaining 1.6 s (`perf`, `VA_JIT=on`): integrator 21 %, dense LU 13 %,
JIT-compiled model ~8 % plus ~10 % of surrounding glue, memmove/malloc ~9 %.

## Windows re-run (2026-10-24) — `outputs_windows/`

The four verilog-a-sim cases, re-run on Windows 11 (Intel Core i7-1185G7, 4 cores / 8 threads)
with verilog-a-sim 2.42.0+1 (7321404, rustc 1.92 windows-gnu). ngspice and OpenVAF are not
installed on that machine, so the ngspice cases were not re-run; accuracy is computed against
the stored `outputs/ng_tran_tight` and the closed form, with the same definitions as
`make_reference.py`. Runner: `va_rerun_windows.py` (the va-sim half of `make_reference.py`;
wall time by `perf_counter`, memory = peak working set, so RSS figures are not directly
comparable with Linux `/usr/bin/time`).
