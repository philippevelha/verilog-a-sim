# Benchmark circuits

Decks that exercise the simulator on **real vendor compact models** rather than on the model
zoo, and decks that reproduce bugs those models found.

These are deliberately **not** part of `cargo xtask validate`. Most of them need a `.va` file
from `external/`, which is gitignored, so they cannot be gated on — and that is precisely the
gap they exist to cover: every bug recorded here survived a green 28/28 gate, because nothing
in the zoo looked like them.

| deck | needs | what it is for | plot |
|---|---|---|---|
| `cap_fast_edge.net` | nothing | Minimal reproduction of the LTE timestep-underflow fixed in 1.2.5. Self-contained: reference capacitor, resistor and waveform source, no Verilog-A. | — |
| `psp103_inverter_vtc.net` | `psp103.va` | CMOS inverter transfer curve. Rails at 1.200000 V and 7.49e−9 V, steepest slope 69.1 V/V near 0.576 V. | [`psp103_inverter_vtc.svg`](../../docs/examples/psp103_inverter_vtc.svg), and [`psp103_inverter_crowbar.svg`](../../docs/examples/psp103_inverter_crowbar.svg) for `I(Vmeas)` over the same sweep |
| `psp103_inverter_tran.net` | `psp103.va` | The same inverter switching, five cycles of a 2 ns clock. Impossible before 1.2.5 for two independent reasons. | [`psp103_inverter_tran.svg`](../../docs/examples/psp103_inverter_tran.svg) |
| `hicum_output_family.net` | `hicumL2V3p0p0.va` | One inner sweep of a nested `.dc` output family. | — |
| `psp103_inverter_card_vtc.net` | `psp103.va` | The same inverter **with the reference model card** — 269 parameters per device from `external/benchmarkExt`, not `.va` defaults. | [vtc](../../docs/examples/psp103_inverter_card_vtc.svg), [crowbar](../../docs/examples/psp103_inverter_card_crowbar.svg) |
| `psp103_inverter_card_tran.net` | `psp103.va` | The same, switching. 3.99 s for 1810 points. | [tran](../../docs/examples/psp103_inverter_card_tran.svg) |

Plots are regenerated by adding `--plot <path>` to the command in each deck's header; the series
plotted are whatever `--report` selects.

[`nand/`](nand/) holds the same CMOS NAND2 built from thirteen different MOSFET models — twelve
vendor ones and this project's own. Its README records which solve and which do not, and the
four separate causes behind the ones that do not. A NAND is there because its series stack has an
internal node that floats when the lower device is off, which a single transistor never
exercises.

The `_card_` pair is the same circuit as the plain `psp103_inverter_*` decks with the real model
card folded onto the device lines, because when they were converted this parser had no `.model`
card and no `+` continuation (it has both since 1.11.0). Keeping both is deliberate: the difference between them is exactly what a model
card is worth, and `benchmark.md` § 3 quotes it.

Each file's header says how to run it, what it should produce, and — for the ones adapted from
external decks — exactly how it differs from the deck it came from. Those differences matter
more than the numbers: none of these run on their original text, because `.subckt`,
`.param`/`'expr'`, `+` continuation lines and nested `.dc` are all unsupported, and no model
cards were available, so every one of them runs on the `.va` file's default parameters.

`benchmark.md` at the repository root carries the measured figures and the methodology.
